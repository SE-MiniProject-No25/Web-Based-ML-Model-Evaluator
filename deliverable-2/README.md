## What the video shows

Upload, configure and review; running an evaluation and reading the results table with its plain-language metric explanations and the chart; downloading the result file; different kinds of models (three classes, regression, a scikit-learn pipeline on a real dataset); a malformed CSV, a mismatched evaluation and a corrupt model being stopped with clear messages; the documented API; and the test results (288 automated tests, 98.0% line and 95.5% branch coverage, all 25 Test Plan cases passing, see [`docs/`](../docs/)).

## Rebuilding the video

```bash
cd deliverable-2/video
python build_video.py                # voice-over with the Windows voice "Zira" (needs ffmpeg and Pillow)
python build_video.py --silent       # no voice, to record your own over it
python build_video.py --voice David  # another installed Windows voice
```

The voice-over is generated by the Windows speech engine, which sounds synthetic. For the final submission the team can record their own voice over the silent version, reading the narration in the script file. The screenshots were captured at 800×450 so every pixel is real, then scaled into the video frame.

## Re-creating the demo inputs

```bash
cd deliverable-2/demo-inputs
python make_demo_inputs.py --verify
```

This needs the backend dependencies (`pip install -r backend/requirements-dev.txt`).
