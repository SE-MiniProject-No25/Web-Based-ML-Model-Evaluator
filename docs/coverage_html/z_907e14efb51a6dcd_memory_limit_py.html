1"""Memory limit for an evaluation child process on Windows (NFR-10, SEC-04, TC-15). 

2 

3On Linux and macOS the worker caps its own address space with ``resource.setrlimit``. Windows has no 

4such call, so the server puts the child in a *job object* whose per-process memory limit the operating 

5system enforces: an allocation beyond it fails, and Python raises ``MemoryError`` in the child, which 

6the worker reports as ``RESOURCE_LIMIT_EXCEEDED``. The job also kills the child if the server closes it. 

7 

8The child is added to the job right after it starts, while the interpreter is still starting up and 

9long before the model is loaded, so the limit covers the model and the data. 

10"""
